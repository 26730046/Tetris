\begin{frame}{4. Triển khai trên Git: Quản lý Code \& Giải quyết Conflict}
    Khi ghép code từ nhiều thành viên (ví dụ: ghép Module Hiển thị vào Game Loop), Git xảy ra tình trạng \textbf{Merge Conflict}.\\
    \vspace{0.2cm}
    \textbf{Quá trình nhóm giải quyết Conflict thực tế:}
    \begin{itemize}
        \item \textbf{Nguyên nhân:} Bạn Long (Game Loop) và bạn Anh (Hiển thị) cùng đẩy code sửa trên file \texttt{main.cpp}.
        \item \textbf{Xử lý:} Hai bạn xem xét các dòng code báo đỏ (HEAD và nhánh cần merge), chốt giữ lại vòng lặp của Long và hàm \texttt{draw()} của Anh.
        \item \textbf{Kết quả:} \texttt{git add} và \texttt{git commit} để hoàn thành merge.
    \end{itemize}
